# Learning objectives

- Trace DNS discovery, Kerberos ticket issuance and authorization in a fresh Windows sign-in.
- Explain why LDAP signing and TLS certificate validation address different protocol properties.
- Apply account policy and separate ordinary, delegated, directory administrative and service identities.
- Distinguish effective endpoint settings from the policy objects intended to enforce them.
- Verify access through positive and denied operations, then correlate configuration and event evidence.
- Present audit changes and unknowns with a reproducible denominator and a clear recovery boundary.

The [interview guide](interview.md) connects each objective to a demonstration and evidence question.
